# CommunityNoticeBot 릴리스 점검표

구성, 공지, 릴레이 이야기, 게임 보상, 현지화 또는 마이그레이션 동작을 변경하는 모든
릴리스에서 이 점검표를 완료합니다. 배포 기록에 릴리스 버전, 검토자, 일자, 테스트 길드,
증적 링크를 남기되 토큰·데이터베이스 URL·Discord ID는 이 저장소에 기록하지 않습니다.

## 자동화 게이트

- [ ] 프로젝트 의존성을 설치한 환경에서 `python3 -m unittest discover -s tests -v`를 실행합니다.
- [ ] 로캘 카탈로그 테스트를 통과합니다. 한국어와 영어는 키와 서식 자리표시자가 정확히 같아야 합니다.
- [ ] `git diff --check`를 실행합니다.

## 문구 검토

- [ ] 소유자가 한국어 카탈로그와 한국어 안내 문서를 검토·승인합니다.
- [ ] 소유자가 영어 카탈로그와 영어 안내 문서를 검토·승인합니다.
- [ ] [현지화 기여 및 검토 절차](localization-review.ko.md)를 따르고, 한국어·영어
  문구 검토자와 승인 일자를 기록합니다.
- [ ] 명령 동기화 후 Discord에서 두 언어의 새 명령 메타데이터를 검토합니다.

## 새 서버 점검

- [ ] 토큰/데이터베이스 설정 외의 서버 전용 환경 변수 없이 새 테스트 서버에 봇을 초대합니다.
- [ ] `/admin setup start`를 실행하고 두 언어를 차례로 선택합니다. `/admin setup status`와
  구성원 게임 도움말에 누락 키나 내부 식별자가 없는지 확인합니다.
- [ ] 대기열을 만들고 신청을 열어 제출·게시한 뒤 감사 기록을 확인합니다. 실패/재시도 게시도
  반복하여 중복 게시나 보상이 없음을 확인합니다.
- [ ] 릴레이 이야기 두 개를 만들고 기여 순서와 보상이 이야기 경계를 넘지 않는지 확인합니다.
- [ ] 필요한 채널 권한을 하나 제거하여 복구 가능한 진단을 확인하고, 권한 복원 후 안전하게 재시도합니다.

## 기존 서버 전환 및 복구

- [ ] 전환 전에 복원 가능한 PostgreSQL 백업을 만들고 보관합니다.
- [ ] `/admin diagnostics migration`을 비공개 매니페스트와 비교하고, 일반화 스케줄러를 켜기 전에
  모든 불일치를 해결합니다.
- [ ] 토막 일일 주기 1회와 교훈 주간 주기 1회를 관찰하고, 각각 게시 1회, 최종 보상 1건,
  기여자 DM, 공개 스레드 알림을 기록합니다.
- [ ] 스테이징에서 백업 및 중단 작업 상태로 복구 절차를 연습합니다.
- [ ] 게임 마이그레이션 행 수와 월드 JSON을 마이그레이션 증적과 비교하며, `si_*` 기록을 덮어쓰지 않습니다.

## 레거시 폐기 결정

위의 적용 항목마다 증적이 기록되고 배포 소유자가 폐기를 승인하기 전에는 레거시 이름, 명령 처리,
스케줄러 경로, 환경 구성을 제거할 수 없습니다. 결정이 완료될 때까지 마이그레이션 복구 절차를 유지합니다.
