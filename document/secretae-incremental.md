# 시크리타이 인크리멘탈 상세 안내

시크리타이 인크리멘탈은 **비밀 유기체**로 비밀 파편을 생산하고, 파편으로
**비밀**을 합성한 뒤, 충분히 성장했을 때 **농축**으로 이야기의 정수를 얻는
증분 게임입니다. 게임 안에서는 `/게임 도움말`로 짧은 안내를 다시 볼 수 있습니다.

## 숫자 표시

모든 자원은 정수처럼 취급합니다. 화면에는 소수점 이하를 버려서 표시합니다.

- `10,000` 미만은 일반 정수로 표시합니다. 예: `9999`
- 그 이상은 과학적 표기법을 사용합니다. 예: `3.86e7`은 약 38,600,000입니다.
- 지수도 너무 커지면 중첩 표기법을 사용합니다. 예: `3e4.12e8`은
  `3 × 10^(4.12 × 10^8)`을 뜻합니다.

## 시작 상태

처음 게임 기록이 만들어지면 다음 자원을 받습니다.

| 자원                    | 시작 수량 |
| ----------------------- | --------: |
| 비밀 파편               |         1 |
| 이야기의 정수           |         0 |
| 각 비밀 유기체          |         1 |
| 각 색 비밀 및 형태 비밀 |       100 |

색 비밀과 유기체는 빨강, 주황, 노랑, 초록, 파랑, 보라, 하양, 검정의 여덟 단계입니다.
형태 비밀은 ◯, □, ♡의 세 종류입니다.

## 생산

`/게임 생산`은 하루 한 번 사용할 수 있으며, **오전 5시(KST)** 에 생산 가능 횟수가
초기화됩니다. 검정부터 빨강 방향으로 계산하므로, 높은 등급 유기체가 이번 생산에서
만든 유기체도 바로 다음 낮은 등급 계산에 반영됩니다.

색 `c`의 생산에 사용하는 값은 다음과 같습니다.

```text
유효 비밀(c) = 색 비밀(c) × (1 + ◯ 비밀 / 100)
원시 생산량(c) = 유기체(c) × (유효 비밀(c)^1.05 / 125) × 은하수 배율
획득량(c) = ceil(원시 생산량(c)^(1 + 이야기의 정수 / 240))
```

은하수 크기는 서버 전체 이야기의 정수 합계에 1을 더한 값입니다. 은하수 배율은 각 유기체의 생산량을 증가시킵니다.

```text
은하수 크기 = 서버 전체 이야기의 정수 + 1
은하수 배율 = 0.2 + 0.035 × ln(은하수 크기)
```

검정~주황 유기체의 획득량은 바로 한 단계 낮은 유기체에 더해집니다. 빨강 유기체의
획득량은 비밀 파편에 더해집니다. 중간 계산에서는 반올림하지 않고, 각 색의 최종
획득량에서만 `ceil`을 적용합니다.

## 비밀 합성

`/게임 합성 <비밀> <수량>`은 비밀 파편을 사용해 색 또는 형태 비밀을 만듭니다.
같은 종류의 비밀을 많이 보유할수록 가격이 오릅니다.

현재 해당 비밀 수량을 `a`라고 하면, 다음 한 개의 할인 전 가격은 다음과 같습니다.

```text
다음 1개의 기본 가격 = 1.1^(a / 100)
```

`n`개를 한 번에 합성할 때는 각각의 가격을 하나씩 반복해서 더하지 않고, 위 등비수열의
합으로 계산합니다. 기본 가격에는 두 가지 할인이 차례로 적용됩니다.

```text
정수 따라잡기 할인 = min((서버 최고 정수 - 내 정수) / 100, 0.5)
□ 비용 배율 = 1 / (1 + ln(1 + □ 비밀) / 17)
최종 가격 = max(1, floor(기본 가격 × (1 - 정수 따라잡기 할인) × □ 비용 배율))
```

정수 따라잡기 할인은 서버 최고 정수보다 낮은 플레이어만 받으며, 최대 50%입니다.
마지막 `floor`와 최소 가격 1은 플레이어에게 유리하게 적용됩니다.

`/게임 최대합성`은 같은 가격 규칙으로 가능한 최대 묶음을 찾아 구매합니다. 우선순위는
다음과 같으며, 앞선 종류를 살 수 있는 한 먼저 사용합니다.

```text
◯ → □ → ♡ → ⬛️ → ⬜️ → 🟪 → 🟦 → 🟩 → 🟨 → 🟧 → 🟥
```

`/게임 가격`은 현재의 모든 다음-1개 가격, 할인, 농축 예상치를 비공개로 보여 줍니다.
가격 확인은 자원을 소비하거나 생산 횟수를 사용하지 않습니다.

## 형태 비밀의 효과

| 비밀 | 효과                                                        |
| ---- | ----------------------------------------------------------- |
| ◯    | 모든 색 비밀의 생산 계산에 `1 + ◯ / 100` 배율을 적용합니다. |
| □    | 합성 비용에 `1 / (1 + ln(1 + □) / 17)` 배율을 적용합니다.   |
| ♡    | 농축으로 얻는 이야기의 정수를 높입니다.                     |

## 농축

농축은 성장 단계를 새로 시작하는 대신 이야기의 정수를 얻습니다. `/게임 농축`은 먼저
비공개 확인 화면을 보여 주며, 확인할 때 현재 상태를 다시 계산합니다. 따라서 미리 보기
후 다른 활동으로 수량이 바뀌면 실제 획득량도 달라질 수 있습니다.

농축은 플레이어마다 **일주일에 한 번만** 할 수 있으며, 가능 횟수는 매주 **월요일
오전 5시(KST)** 에 초기화됩니다.

```text
기본 정수 = max(0, ceil(ln(비밀 파편) / ln(10^15)))
♡ 배율 = 1 + ceil(♡ 비밀 / 100)
농축 획득 정수 = 기본 정수 × ♡ 배율
```

농축 획득량은 현재 이야기의 정수를 기반으로 부드럽게 복리 성장합니다. 위 식의
`기본 정수 × ♡ 배율`을 `R`, 현재 이야기의 정수를 `E`라고 하면 다음 식을 적용합니다.

```text
완료한 성장 단계의 효율 = max(0, log10(log10(R + 1)))
농축 획득 정수 = ceil((E + 1) × (1 + 완료한 성장 단계의 효율))
```

성장 단계의 성과는 이중 로그로 반영되므로, 극단적으로 큰 비밀 파편이 한 번의
농축으로 여러 지수 구간을 건너뛰지 않습니다. 반면 현재 정수가 획득량의 기반이므로,
매주 농축할수록 정수의 지수는 플레이어의 성장에 따라 점진적으로 증가합니다.


획득 정수가 0이면 농축할 수 없습니다. 성공한 농축은 다음 자원을 초기 상태로 되돌립니다.

- 비밀 파편: 1
- 모든 비밀 유기체: 각각 1
- 모든 색/형태 비밀: 각각 100

이야기의 정수는 초기화되지 않으며, 서버 전체 은하수 크기에도 즉시 반영됩니다.

## 게임 알림

`/게임 알림`은 명령어를 실행한 사람에게만 보이는 설정 화면을 엽니다. 알림 설정은
플레이어별로 따로 저장되며, 기본값은 알림을 받지 않는 상태입니다.

첫 화면에서 다음 중 하나를 선택합니다.

- **알림 끄기**: 모든 게임 알림을 해제합니다.
- **농축 마감 알림**: 이번 농축 주기에 유효한 `/게임 농축`을 완료하지 않았다면,
  농축 가능 횟수가 초기화되기 전 마지막 설정 시각에 DM을 보냅니다.
- **매일 게임 알림**: 해당 게임 날짜에 `/게임` 명령어를 아직 사용하지 않았다면,
  매일 DM을 보냅니다. 또한 농축을 완료하지 않은 경우에는 농축 마감 전 마지막
  설정 시각에도 농축 알림을 함께 보냅니다.

농축 또는 매일 알림을 선택하면 수신 시각을 0시부터 23시까지의 KST 기준 시각으로
고릅니다. 농축 마감 전 마지막 설정 시각은 선택한 시각이 5시~23시면 일요일 해당
시각, 0시~4시면 월요일 해당 시각입니다. 설정 시각에 조건을 만족할 때만 DM이
전송됩니다. 게임 날짜는 생산 횟수와 마찬가지로 오전 5시(KST)에 바뀝니다.

## 게시판 보상

이야기잇기와 공개된 토막상식은 각각 모든 11종 비밀에 아래 보상을 적용합니다.

```text
새 비밀 수량 = floor(기존 비밀 수량 × 1.05)
```

공개된 이 주의 교훈은 이야기의 정수를 보상합니다. 기존 정수가 1 이상이면 두 배가 되고,
0이면 첫 보상으로 1을 받습니다. 자세한 게시판 규칙은
[게시판과 보상 안내](community-features.md)를 참고하세요.
