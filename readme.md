# SecretRoomBot 안내

SecretRoomBot은 서버의 이야기잇기, 이 주의 교훈, 오늘의 토막상식 게시판과
함께 즐기는 **시크리타이 인크리멘탈** 게임을 제공합니다. Discord에서 `/`를
입력하면 사용할 수 있는 명령어를 확인할 수 있습니다.

## 빠른 안내

- [시크리타이 인크리멘탈](document/secretae-incremental.md): 게임 규칙, 생산, 합성, 농축, 알림
- [게시판과 보상](document/community-features.md): 이야기잇기, 교훈, 토막상식

## 시크리타이 인크리멘탈

비밀 유기체를 생산해 **비밀 파편**을 얻고, 파편으로 비밀을 합성하여 성장하는
게임입니다. 모든 수치는 매우 커질 수 있으므로 큰 수는 과학적 표기법으로 표시됩니다.

| 명령어                     | 설명                                                                        |
| -------------------------- | --------------------------------------------------------------------------- |
| `/게임 도움말`             | 게임의 짧은 안내를 표시합니다.                                              |
| `/게임 현황`               | 비밀 파편, 이야기의 정수, 유기체, 모든 비밀의 보유량을 봅니다.              |
| `/게임 생산`               | 유기체 생산을 실행합니다. 하루 한 번 가능하며 오전 5시(KST)에 초기화됩니다. |
| `/게임 합성 <비밀> <수량>` | 비밀 파편으로 원하는 색/형태 비밀을 합성합니다.                             |
| `/게임 최대합성`           | ◯, □, ♡, 검정부터 빨강 순으로 가능한 만큼 합성합니다.                       |
| `/게임 가격`               | 다음 합성 가격과 농축 예상치를 비공개로 봅니다.                             |
| `/게임 농축`               | 자원을 초기화하고 이야기의 정수를 얻습니다. 확인 후에만 실행됩니다.         |
| `/게임 알림`               | 게임 미참여 알림의 종류와 수신 시각(KST)을 설정합니다.                      |

색 비밀은 같은 색의 유기체 생산을 강화합니다. 형태 비밀은 다음 효과를 가집니다.

- ◯: 모든 색 비밀의 생산 효과를 높입니다.
- □: 합성 비용을 낮춥니다.
- ♡: 농축으로 얻는 이야기의 정수를 높입니다.

## 게시판 기능

이야기잇기는 200자 이내의 글을 순서대로 이어 쓰는 게시판입니다. 같은 사람이
연속으로 작성할 수 없으며, 규칙에 맞는 글은 모든 비밀을 1.05배로 올립니다.

토막상식과 교훈은 각각의 신청 게시판에서 받습니다. 신청 그 자체가 아니라 실제로
공개 게시된 뒤에만 보상이 지급됩니다. 자세한 작성 규칙과 보상은
[게시판과 보상 안내](document/community-features.md)에서 확인하세요.

## 운영 및 개발

봇은 PostgreSQL 데이터베이스와 Discord 토큰이 필요합니다. `.env`에
`DISCORD_TOKEN`과 `DATABASE_URL`을 설정한 뒤 의존성을 설치하고 `main.py`를 실행합니다.
새 버전을 GitHub에 푸시하면 Railway 배포 설정에 따라 자동 배포할 수 있습니다.

기존 시크리타이의 공장형 게임 코드는 `legacy/secreate/`에 보관되어 있으며,
실행 중인 봇은 Incremental 게임만 불러옵니다.
