# SecretRoomBot 안내

이 봇은 서버 멤버들이 함께 즐길 수 있는 게시판 관리 기능과 시크리타이 게임을 제공합니다.  
모든 명령어는 채팅창에 `/`를 입력하면 목록에서 확인할 수 있습니다.

---

## 시크리타이 게임

이모지로 가득 찬 공장을 운영하여 **Secret**을 모으는 수집 게임입니다.

### 기본 개념

**Secret**이란?  
게임 내 재화입니다. 빨강·주황·노랑 같은 **색깔 Secret**과 동그라미·네모·하트 같은 **모양 Secret**으로 나뉩니다.

**공장**이란?  
이모지들이 격자 모양으로 배열된 나만의 공간입니다.  
공장을 가동하면 배열된 이모지의 패턴에 따라 Secret이 생산됩니다.

**어떻게 많이 생산하나요?**  
같은 색깔 또는 같은 모양의 이모지가 상하좌우로 많이 연결될수록 생산량이 늘어납니다.  
예를 들어 빨간 이모지 2개가 붙어 있으면 4, 3개가 붙어 있으면 9를 생산합니다.

```text
연결 1개 ->  1
연결 2개 ->  4
연결 3개 ->  9
연결 4개 -> 16
...
```

### 명령어

| 명령어 | 하는 일 |
|---|---|
| `/게임 등록` | 게임을 시작합니다. 공장 3개와 기본 아이템 슬롯 3개가 지급됩니다. |
| `/게임 프로필` | 내가 보유한 Secret, 공장, 아이템, 이야기의 정수를 확인합니다. |
| `/게임 생산` | 공장 하나를 골라 오늘의 Secret을 생산합니다. |
| `/게임 공장 [번호]` | 해당 번호 공장의 이모지 배열을 자세히 봅니다. |
| `/게임 아이템` | 아이템을 사용, 강화, 변환, 분해합니다. |

### 생산 규칙

- 생산은 하루에 한 번만 할 수 있습니다.
- 매일 오전 6시(한국 시간)에 초기화되어 다시 생산할 수 있습니다.
- 보유한 공장 중 원하는 공장을 직접 골라 가동합니다.
- 이야기의 정수를 보유했다면, 이미 오늘 생산했을 때 한 번 더 생산할 수 있습니다.

### 아이템

아이템은 공장을 바꾸거나 Secret을 다른 종류로 바꾸는 도구입니다.  
아이템 슬롯은 3칸이며, 처음에는 빈 깡통으로 시작합니다.

아이템 종류:

| 아이템 | 효과 |
|---|---|
| 마법 붓 | 선택한 위치 주변을 특정 색으로 칠합니다. |
| 조각도 | 선택한 위치 주변을 특정 모양으로 세공합니다. |
| 비밀 정제기 | 모양 Secret을 소모해 색깔 Secret을 생성합니다. |
| 비밀 압착기 | 색깔 Secret을 소모해 모양 Secret을 생성합니다. |
| 빈 깡통 | 기능이 없는 빈 슬롯입니다. 강화하면 랜덤 아이템이 됩니다. |

아이템 규칙:

- 아이템 사용은 하루 3회 제한입니다.
- `+0` 아이템은 사용할 수 없습니다. 먼저 강화해야 합니다.
- 강화에는 모양 Secret이 필요합니다.
- 변환에는 색깔 Secret이 필요하며, 같은 아이템으로 다시 변환되지는 않습니다.
- 분해하면 아이템이 빈 깡통으로 돌아가고 일부 Secret을 돌려받습니다.
- 이야기의 정수를 보유했다면, 이미 아이템 사용 3회를 모두 쓴 뒤 한 번 더 사용할 수 있습니다.

## 이야기잇기 게시판

이야기잇기 게시판은 서버 멤버들이 순서대로 짧은 글을 이어 쓰는 공간입니다.

규칙:

- 한 번에 200자 이내로 작성해야 합니다.
- 같은 사람이 연속으로 두 번 작성할 수 없습니다.
- 규칙을 어긴 메시지는 삭제되며, 삭제 사유와 작성 내용이 DM으로 안내됩니다.

시크리타이 보상:

- 규칙에 맞는 글이 게시판에 남으면 **이야기의 정수** 1개를 얻습니다.
- 이야기의 정수는 아이템 슬롯을 차지하지 않는 티켓입니다.
- 보유한 이야기의 정수는 `/게임 프로필` 또는 `/게임 아이템`에서 확인할 수 있습니다.
- 보유량이 0개일 때는 표시되지 않습니다.
- 보상 안내는 작성자에게 DM으로만 전달됩니다.
- 아직 시크리타이를 시작하지 않은 사람도 보상을 받을 수 있으며, 이 경우 기본 게임 계정이 자동으로 생성됩니다.

## 교훈 신청 게시판

교훈 신청 게시판은 서버에 게시될 교훈을 신청하는 공간입니다.

사용 절차:

- 가장 최근 교훈 신청 스레드에 교훈을 작성합니다.
- 지난 스레드에 작성한 신청은 인정되지 않고 삭제됩니다.
- 한 신청 기간에는 한 번만 신청할 수 있습니다.
- 이미 게시된 교훈 신청을 수정하거나 삭제하면 DM으로 안내됩니다.

시크리타이 보상:

- 유효한 교훈 신청이 등록되면 즉시 시크리타이 보상을 받습니다.
- 보유한 모든 공장이 각각 10번씩 추가 생산됩니다.
- 교훈 신청 기회는 자주 오지 않으므로 보상 규모가 큽니다.
- 보상 안내는 신청자에게 DM으로만 전달됩니다.
- 아직 시크리타이를 시작하지 않은 사람도 보상을 받을 수 있으며, 이 경우 기본 게임 계정이 자동으로 생성됩니다.
