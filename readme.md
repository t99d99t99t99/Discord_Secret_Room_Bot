# SecretRoomBot 안내

이 봇은 서버 멤버들이 함께 즐길 수 있는 기능들을 제공합니다.  
모든 명령어는 채팅창에 `/`를 입력하면 목록에서 확인할 수 있습니다.

---

## 시크리타이 게임

이모지로 가득 찬 공장을 운영하여 **Secret**을 모으는 수집 게임입니다.

### 기본 개념

**Secret**이란?  
게임 내 재화입니다. 빨강·주황·노랑 같은 **색깔 Secret**과 동그라미·네모·하트 같은 **모양 Secret**으로 나뉩니다.

**공장**이란?  
이모지들이 격자 모양으로 배열된 나만의 공간입니다.  
공장을 가동하면 배열된 이모지의 패턴에 따라 Secret이 생산됩니다.

**어떻게 많이 생산하나요?**  
같은 색깔 또는 같은 모양의 이모지가 상하좌우로 많이 연결될수록 생산량이 늘어납니다.  
예를 들어 빨간 이모지 2개가 붙어 있으면 4, 3개가 붙어 있으면 9를 생산합니다.  
많이 연결할수록 훨씬 많이 생산되는 구조입니다.

```
연결 1개 →  1
연결 2개 →  4
연결 3개 →  9
연결 4개 → 16
...
```

---

### 명령어

| 명령어              | 하는 일                                                             |
| ------------------- | ------------------------------------------------------------------- |
| `/게임 등록`        | 게임을 시작합니다. 공장 3개가 지급됩니다. 처음 한 번만 하면 됩니다. |
| `/게임 프로필`      | 내가 보유한 Secret과 공장 목록을 확인합니다.                        |
| `/게임 생산`        | 공장 하나를 골라 오늘의 Secret을 생산합니다.                        |
| `/게임 공장 [번호]` | 해당 번호 공장의 이모지 배열을 자세히 봅니다.                       |

### 생산 규칙

- 생산은 **하루에 한 번**만 할 수 있습니다.
- 매일 **오전 6시(한국 시간)** 에 초기화되어 다시 생산할 수 있습니다.
- 보유한 공장 중 원하는 공장을 직접 골라 가동합니다.
